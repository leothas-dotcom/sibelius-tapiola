# Brief: soitinten merkitykset Tapiola-kirjallisuudessa

Lue ensin `CLAUDE.md` kokonaan ja `docs/tutkimus/teos.md` luvut 5 ja 6. Kirjoita tulos tiedostoon
`docs/tutkimus/soittimet.md` suomeksi.

## Mitä etsitään
Käyttäjä muistaa lukeneensa: "alun jousiteemat on kuin Tapion metsät, ja sitten eri puhaltimet nousevat
taustalta kuin vuoret." Tehtävä: **löydä, kuka on kirjoittanut Tapiolan soitinryhmistä kuvina**, ja mitä kukin
soitinryhmä kirjallisuuden mukaan "tarkoittaa" tai kuvaa. Soitinryhmät: jouset (ydinmotiivi, tremolot, divisi,
sordiinot), puupuhaltimet (huilut, oboet, englannintorvi, klarinetit, bassoklarinetti, fagotit, kontrafagotti),
käyrätorvet, trumpetit, pasuunat, patarummut, kontrabassojen urkupisteet.

Hakusanoja: "Tapiola" + metsä / forest / vuoret / mountains / horisontti / horizon / peikot / sprites / goblins /
"wood-sprites" / Tapio / haltiat / myrsky / storm / tuuli / wind / lumi / snow / usva / mist / huuto / cry /
"the forest god" / "strings" / "woodwind" / "brass" / "timpani" / "pedal point" / "ostinato" / "tremolo".
Suomeksi ja englanniksi, myös saksaksi ja ruotsiksi (Wald, Berge, skog, berg).

Lähteet: Sibelius-klubi (fi, en), yle.fi (RSO:n käsiohjelmat, Yle Klassinen), Helsingin kaupunginorkesteri,
Sinfonia Lahti, BIS/Ondine/Hyperion/Naxos/DG/Decca-levytekstit, BBC Proms ja Yhdysvaltain orkesterien
ohjelmakirjat, Tovey (1939), Tawaststjerna, Salmenhaara (1970, 1984), Layton, Hepokoski, Howell, Grimley,
Murtomäki, Goss, Burnett-James, Abraham (*The Music of Sibelius*, 1947), Ringbom, Ekman, Johnson, Rickards.
Google Books- ja JSTOR-esikatselut sallittuja.

## Tuloste
1. Taulukko soitinryhmittäin: ryhmä → mitä lähde sanoo sen kuvaavan tai tekevän (lyhyt lainaus alle 15 sanaa tai
   parafraasi) → missä kohtaa teosta (jos lähde kertoo: kirjain, tahti, "alussa", "myrskyssä") → lähde → luotettavuus.
2. Erikseen: löytyikö "puhaltimet nousevat kuin vuoret" -luenta tai vastaava, ja keneltä. Jos ei, sano suoraan.
3. Luettelo kaikista kirjallisuuden käyttämistä kuvista (metsä, vuori, peikko, haltia, jumala, myrsky, tuuli, lumi,
   usva, hiljaisuus, huuto, kutsu, vaeltaja, aurinko, hämärä jne.) ja kuka kutakin käyttää.
4. Lähdeluettelo.

## Säännöt
- Ei keksittyjä lainauksia; "ei löytynyt", jos ei löydy; hakukoneen ote merkitään "[vain hakutuloksen ote]".
- Sävelnimet suomeksi: englannin B minor on h-molli, B major H-duuri; suomen B on englannin B♭.
- Ei visuaalisia ehdotuksia tähän dokumenttiin. Vain mitä kirjallisuus sanoo.
- Suomeksi, 1000–2000 sanaa.
- Musiikkisanasto muusikon suomeksi: sordiino (ei "mykistin"), divisi, tremolo, urkupiste, harjoituskirjain; epävarma termi italiaksi.
